## 자, 다음 문제 (3개 중 2번)

### [Setting]
차량은 짧은 시간 동안 같은 종류의 이벤트를 여러 번 발생시킬 수 있어 (예: 급제동 detection이 1초 안에 3번 trigger). Cloud로 보낼 때는 이런 **burst를 하나의 이벤트로 합쳐서** 보내야 해 — 안 그러면 같은 사건이 중복 logging됨.

### [Problem]

```python
    Merge consecutive same-type events within time_window into a single event.
    Keep the EARLIEST timestamp of each burst.
    """
    pass
```

### [Example]
```python
events = [
    (0.0, "hard_brake"),
    (0.3, "hard_brake"),   # 0.3 - 0.0 = 0.3 < 1.0 → merge
    (0.7, "hard_brake"),   # 0.7 - 0.3 = 0.4 < 1.0 → merge
    (2.5, "hard_brake"),   # 2.5 - 0.7 = 1.8 > 1.0 → new burst
    (2.6, "lane_change"),  # different type → new event
    (2.8, "hard_brake"),   # 2.8 - 2.5 = 0.3 < 1.0 → merge with 2.5
]
time_window = 1.0

# Expected:
# [(0.0, "hard_brake"),    # 0.0-0.7 burst, keep earliest
#  (2.5, "hard_brake"),    # 2.5-2.8 burst, keep earliest
#  (2.6, "lane_change")]   # standalone
```

### [Constraints]
- Events already sorted by timestamp
- 길이 up to 100,000
- 같은 type이라도 time_window 넘어서 발생하면 별도 burst
