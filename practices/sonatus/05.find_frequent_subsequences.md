## 자, 마지막 문제 (3개 중 3번)

다른 패턴. 이번엔 약간 더 algorithmic해.

### [Setting]
Sonatus AI Director는 차량 fleet에서 자주 발생하는 **event sequence (패턴)**을 찾고 싶어해. 예: *"hard_brake → lane_change → hard_brake"* 같은 sequence가 N번 이상 나타나면 그건 위험 운전 패턴일 수 있어.

### [Problem]
주어진 event log에서, **길이 K인 모든 sub-sequence**의 빈도수를 계산하고, **가장 자주 등장한 top-N개 sub-sequence를 반환**.

```python

    k: int,                 # subsequence length, e.g., 3
    n: int                  # top N to return
) -> list[tuple[tuple[str, ...], int]]:
    """
    Return top-N most frequent length-K subsequences with their counts.
    Sub-sequence = CONTIGUOUS window of length K (sliding window).
    """
    pass
```

### [Example]
```python
event_log = ["brake", "lane_change", "brake", "lane_change", "brake", "accelerate", "brake", "lane_change", "brake"]
k = 3
n = 2

# All length-3 subsequences (sliding):
# ("brake", "lane_change", "brake")   - appears 3 times
# ("lane_change", "brake", "lane_change") - 2 times
# ("brake", "lane_change", "accelerate") - 1 time
# ("lane_change", "accelerate", "brake") - 1 time
# ("accelerate", "brake", "lane_change") - 1 time

# Expected (top 2):
# [(("brake", "lane_change", "brake"), 3),
#  (("lane_change", "brake", "lane_change"), 2)]
```

### [Constraints]
- `len(event_log)` up to 100,000
- `k` typically 2~5
- `n` small (5~10)
