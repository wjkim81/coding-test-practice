## 문제: Per-Vehicle API Rate Limiter

### [Setting]
Sonatus Collector AI에 차량들이 API call로 데이터 upload함. 악성/오작동 차량이 폭주하면 system 부하 큼. **차량별로 분당 N회 제한**해야 함. 초과 호출은 reject.

### [Problem]
```python
class VehicleRateLimiter:
    def __init__(self, max_calls_per_minute: int):
        pass
    
    def allow_request(self, vehicle_id: str, timestamp_ms: float) -> bool:
        """
        Return True if request allowed, False if rate-limited.
        Window is sliding 60-second window.
        """
        pass
```

### [Example]
```python
limiter = VehicleRateLimiter(max_calls_per_minute=3)

limiter.allow_request("v1", 0)        # True  (1st call)
limiter.allow_request("v1", 10_000)   # True  (2nd, 10s)
limiter.allow_request("v1", 20_000)   # True  (3rd, 20s)
limiter.allow_request("v1", 30_000)   # False (4th, still within 60s window)
limiter.allow_request("v1", 70_000)   # True  (5th, 1st call now out of window)

limiter.allow_request("v2", 0)        # True  (different vehicle)
```

### [Constraints]
- Vehicle 수 up to 100,000
- 분당 호출 max_calls_per_minute (10-100 정도)
- 가능한 efficient하게
