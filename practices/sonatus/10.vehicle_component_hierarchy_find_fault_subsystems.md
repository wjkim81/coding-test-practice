### [Setting]
차량은 여러 component로 구성됨 (engine, transmission, brake, ...). 각 component는 sub-component를 가질 수 있어 (engine → cylinder1, cylinder2, fuel_injector...). 트리 구조야.

Sonatus AI Technician이 진단 중 특정 sub-tree가 결함인지 판단해야 함. 

### [Problem]

### [Example]

```
            car (not faulty)
           /              \
      engine (not)      brake (not)
       /     \              |
   cyl1     cyl2         pad (FAULTY)
   (not)    (FAULTY)
```

각 component의 subtree:
- `cyl1`: 자기 + (자식 없음). Faulty 없음 → ❌
- `cyl2`: 자기 (FAULTY). → ✅
- `pad`: 자기 (FAULTY). → ✅
- `engine`: 자기 + cyl1 + cyl2 (cyl2 faulty). → ✅
- `brake`: 자기 + pad (faulty). → ✅
- `car`: 자기 + 모든 자손. cyl2, pad faulty 있음. → ✅
