### [Example]

```python
speeds = [100, 110, 105, 120, 115, 90, 95, 130]
window_size = 3

# i=0: skip
# i=1: skip  
# i=2: max([100,110,105]) = 110
# i=3: max([110,105,120]) = 120
# i=4: max([105,120,115]) = 120
# i=5: max([120,115,90])  = 120
# i=6: max([115,90,95])   = 115
# i=7: max([90,95,130])   = 130

# Expected: [110, 120, 120, 120, 115, 130]
```

### [Constraints]
- `len(speeds)` up to 1,000,000
- `window_size` up to 10,000
- 가능한 efficient하게 (naive O(N*W) 말고 더 좋은 거)
