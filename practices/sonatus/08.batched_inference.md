## 문제: Batched Inference for Vehicle Stream

### [Setting]
Sonatus AI Director가 차량 fleet에서 들어오는 sensor data에 대해 ML 모델 inference를 돌려야 해. 차량마다 reading이 비동기적으로 들어오는데, 각 reading 하나씩 모델 돌리면 GPU 활용도가 낮아. **Batching으로 묶어서 한 번에 처리**해야 효율적.

근데 **너무 오래 기다리면 latency 늘어서 안 됨** (OEM 요구: end-to-end latency 100ms 이하).

→ **"Adaptive batching"** 함수를 짜야 해.

### [Problem]
Reading이 stream으로 들어옴. 너 함수는 두 가지 조건 중 하나 충족 시 batch를 flush해서 model inference 돌림:

1. **Size trigger**: Batch가 `max_batch_size`에 도달
2. **Time trigger**: 첫 reading 들어온 후 `max_wait_ms` 지남

```python
class BatchedInference:
    def __init__(
        self, 
        max_batch_size: int = 32,
        max_wait_ms: float = 50.0,
        model_fn: callable = None  # batch → predictions
    ):
        pass
    
    def add_reading(self, reading: dict, timestamp_ms: float) -> list[dict] | None:
        """
        Add reading to current batch.
        Return predictions if batch flushed, else None.
        """
        pass
    
    def flush(self, current_timestamp_ms: float) -> list[dict] | None:
        """
        Force flush current batch (e.g., called periodically by a timer).
        Return predictions if anything flushed, else None.
        """
        pass
```

### [Example]
```python
batcher = BatchedInference(max_batch_size=4, max_wait_ms=50.0, model_fn=my_model)

# Stream simulation
batcher.add_reading({"vehicle_id": "v1", "data": ...}, timestamp_ms=0.0)
# → None (batch size 1, no flush)

batcher.add_reading({"vehicle_id": "v2", "data": ...}, timestamp_ms=10.0)
batcher.add_reading({"vehicle_id": "v3", "data": ...}, timestamp_ms=20.0)
batcher.add_reading({"vehicle_id": "v4", "data": ...}, timestamp_ms=30.0)
# → predictions for [v1, v2, v3, v4] (size trigger, batch=4)

batcher.add_reading({"vehicle_id": "v5", "data": ...}, timestamp_ms=100.0)
# → None (new batch starts)

batcher.flush(current_timestamp_ms=160.0)  
# 100 + 50 = 150 < 160 → time trigger
# → predictions for [v5]
```

### [Constraints]
- Single-threaded (concurrency 무시)
- `model_fn(batch: list[dict]) -> list[dict]`: list 받아서 같은 길이 list 반환
- Edge: 빈 batch flush 호출 시 None
