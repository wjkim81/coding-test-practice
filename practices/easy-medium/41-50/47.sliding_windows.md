**문제: Sliding Window Maximum**

배열과 윈도우 크기 `k`가 주어질 때, 각 윈도우의 **최대값**을 반환하세요.

```
Input:  nums = [1,3,-1,-3,5,3,6,7], k = 3
Output: [3,3,5,5,6,7]

Window:
[1,3,-1] → 3
[3,-1,-3] → 3
[-1,-3,5] → 5
[-3,5,3] → 5
[5,3,6] → 6
[3,6,7] → 7
```

**힌트:** Monotonic Deque! deque에 인덱스를 저장하면서, 앞에서 만료된 거 제거 + 뒤에서 현재보다 작은 거 제거!
