**문제: Daily Temperatures (Monotonic Stack!)**

온도 배열이 주어질 때, 각 날에 대해 **더 따뜻한 날이 며칠 후에 오는지** 구하세요.

```
Input:  [73, 74, 75, 71, 69, 72, 76, 73]
Output: [1,  1,  4,  2,  1,  1,  0,  0]
```

`73`도 → 다음 날 `74`도로 더 따뜻 → 1일
`75`도 → 4일 후 `76`도에서야 더 따뜻 → 4

**힌트:** Stack에 인덱스를 저장하면서, 현재 온도가 stack top보다 높으면 pop!
