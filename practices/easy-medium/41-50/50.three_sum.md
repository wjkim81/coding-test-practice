**문제: 3Sum**

배열에서 합이 0이 되는 **모든 세 수 조합**을 찾으세요. 중복 없이!

```
Input:  [-1, 0, 1, 2, -1, -4]
Output: [[-1, -1, 2], [-1, 0, 1]]

Input:  [0, 1, 1]
Output: []

Input:  [0, 0, 0]
Output: [[0, 0, 0]]
```

**힌트:** 정렬 + 첫 수 고정 + 나머지 Two Pointer!

```
정렬: [-4, -1, -1, 0, 1, 2]
i=0 고정(-4) → left, right로 두 수 찾기
i=1 고정(-1) → left, right로 두 수 찾기
...
```
