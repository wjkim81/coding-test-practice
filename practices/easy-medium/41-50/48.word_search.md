**문제: Word Search (Backtracking + Grid!)**

2D 보드에서 단어를 **상하좌우 연결**로 찾을 수 있는지 판별하세요. 같은 셀 재사용 불가!

```
board = [["A","B","C","E"],
         ["S","F","C","S"],
         ["A","D","E","E"]]

word = "ABCCED" → True
word = "SEE"    → True  
word = "ABCB"   → False (B 재사용!)
```

**힌트:** Backtracking + Grid DFS! 각 셀에서 시작해서 단어 한 글자씩 매칭. 방문 표시하고 → 재귀 → 되돌리기!

풀어봐! 🔥
