**문제: Number of Connected Components (Union-Find!)**

`n`개의 노드와 간선 리스트가 주어질 때, **연결 요소의 개수**를 구하세요.

```
Input:  n=5, edges=[[0,1],[1,2],[3,4]]
Output: 2  # {0,1,2}와 {3,4}

Input:  n=5, edges=[[0,1],[1,2],[2,3],[3,4]]
Output: 1  # 모두 연결
```

**힌트:** Union-Find! `find()`와 `union()` 두 함수만 만들면 돼. 풀어봐! 🔥
