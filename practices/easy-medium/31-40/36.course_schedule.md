**문제: Course Schedule (Topological Sort)**

`numCourses`개의 과목과 선수과목 관계가 주어질 때, **모든 과목을 수강할 수 있는지** 판별하세요. (사이클이 없는지!)

```
Input:  numCourses=2, prerequisites=[[1,0]]
Output: True   # 0→1 순서로 수강 가능

Input:  numCourses=2, prerequisites=[[1,0],[0,1]]
Output: False  # 0→1→0 사이클!
```

이미 다른 세션에서 풀었다고 했지? 빠르게 풀어봐! ⚡
