**문제: Unique Paths (2D DP 첫 문제!)**

`m x n` 그리드에서 왼쪽 위 → 오른쪽 아래로 가는 **경로의 수**. 오른쪽 또는 아래로만 이동 가능.

```
Input:  m = 3, n = 7
Output: 28

Input:  m = 3, n = 2
Output: 3
```

```
[S][ ][ ]
[ ][ ][ ]
[ ][ ][E]

S→E 가는 방법:
→→↓↓, →↓→↓, →↓↓→, ↓→→↓, ↓→↓→, ↓↓→→
```

**힌트:** `dp[i][j]` = (i,j)에 도달하는 경로 수. 위에서 오거나 왼쪽에서 오거나!

```
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```
