**문제: Combination Sum**

후보 숫자 `candidates`에서 합이 `target`이 되는 **모든 조합**을 찾으세요. **같은 수 반복 사용 가능!**

```
Input:  candidates = [2, 3, 6, 7], target = 7
Output: [[2,2,3], [7]]

Input:  candidates = [2, 3, 5], target = 8
Output: [[2,2,2,2], [2,3,3], [3,5]]
```

**힌트:** Subsets 뼈대 + 두 가지 변화:
- base case가 `target == 0`
- 같은 수 반복 가능 → index를 안 올려!
