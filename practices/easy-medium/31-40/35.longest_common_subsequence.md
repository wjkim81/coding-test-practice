**문제: Longest Common Subsequence**

두 문자열의 **가장 긴 공통 부분수열** 길이를 구하세요. (연속 안 해도 됨!)

```
Input:  text1 = "abcde", text2 = "ace"
Output: 3  # "ace"

Input:  text1 = "abc", text2 = "def"
Output: 0
```

**힌트:** 또 2D DP! `dp[i][j]` = text1[:i]와 text2[:j]의 LCS 길이

```
문자가 같으면: dp[i-1][j-1] + 1
다르면:       max(dp[i-1][j], dp[i][j-1])
```

풀어봐! 🔥
