**문제: Redundant Connection**

`n`개의 노드에 `n`개의 간선이 주어져. 원래 트리였는데 간선 하나가 **추가로** 들어와서 사이클이 생겼어. 그 **추가 간선**을 찾으세요.

```
Input:  edges = [[1,2], [1,3], [2,3]]
Output: [2,3]

  1 - 2
  \ /
   3    ← [2,3]이 추가되면서 사이클!
```

```
Input:  edges = [[1,2], [2,3], [3,4], [1,4], [1,5]]
Output: [1,4]
```

**힌트:** 간선을 하나씩 union하다가, **이미 같은 그룹인 두 노드**를 연결하려고 하면? 그게 사이클 만드는 간선!

```
union(1,2) → 다른 그룹 → OK
union(1,3) → 다른 그룹 → OK
union(2,3) → find(2)=1, find(3)=1 → 같은 그룹! → 이게 답!
```

풀어봐! 🔥
