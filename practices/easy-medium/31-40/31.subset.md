**문제: Backtracking 첫 문제 — Subsets**

정수 배열 (중복 없음)의 **모든 부분집합**을 구하세요.

```
Input:  [1, 2, 3]
Output: [[], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]]
```

순서는 상관없어.

**힌트:** 각 원소마다 "넣을까 vs 말까" 선택! 재귀로 트리 탐색:

```
            []
          /    \
       [1]      []
      /   \    /   \
   [1,2] [1] [2]   []
   ...
```

이게 **Backtracking**의 기본 뼈대야. 풀어봐! 🔥
