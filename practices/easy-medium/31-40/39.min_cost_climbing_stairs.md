**문제: Min Cost Climbing Stairs (1D DP 복습)**

계단마다 비용이 있어. 0번 또는 1번 계단에서 시작 가능. 한 번에 1칸 또는 2칸. **최소 비용으로 꼭대기 도달!**

```
Input:  cost = [10, 15, 20]
Output: 15  # 1번(15) → 2칸 점프로 꼭대기

Input:  cost = [1, 100, 1, 1, 1, 100, 1, 1, 100, 1]
Output: 6
```

**힌트:** House Robber랑 거의 같은 뼈대! `dp[i] = cost[i] + min(dp[i-1], dp[i-2])`
