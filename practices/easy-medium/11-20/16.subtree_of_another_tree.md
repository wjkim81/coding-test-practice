**문제: Subtree of Another Tree**

트리 `root` 안에 트리 `subRoot`와 **완전히 같은 서브트리**가 있는지 판별하세요.

```
root:       subRoot:
    3          4
   / \        / \
  4   5      1   2
 / \
1   2
→ True

root:       subRoot:
    3          4
   / \        / \
  4   5      1   2
 / \
1   2
    \
     0
→ False
```

**힌트:** 방금 만든 `same_tree`를 활용해!
