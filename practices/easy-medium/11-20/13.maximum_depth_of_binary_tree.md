**문제: Maximum Depth of Binary Tree**

이진 트리의 **최대 깊이**를 구하세요. (루트에서 가장 먼 리프까지의 노드 수)

```python
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right
```

```
    3
   / \
  9   20
     /  \
    15   7

Output: 3
```
