**LRU Cache**를 구현하세요.

```python
cache = LRUCache(2)  # capacity = 2
cache.put(1, 1)      # {1:1}
cache.put(2, 2)      # {1:1, 2:2}
cache.get(1)         # 1 반환, 1이 최근 사용됨
cache.put(3, 3)      # 2 제거 (가장 오래된), {1:1, 3:3}
cache.get(2)         # -1 (없음)
cache.put(4, 4)      # 1 제거, {3:3, 4:4}
cache.get(1)         # -1
cache.get(3)         # 3
cache.get(4)         # 4
```

**get O(1), put O(1)** 이어야 해!
