**Trie = 문자열 전용 트리!**

일반 트리와 비교:

```
일반 트리:       Trie:
    5              root
   / \           /  |  \
  3   7         a   b   c
 / \           / \      |
1   4         p   n     a
              |   |     |
              p   d     r
              |
              l
              |
              e
              
              저장된 단어: apple, and, car
```

**각 노드가 한 글자**, 루트→리프 경로가 하나의 단어!

---

**핵심 구조:**

```python
class TrieNode:
    def __init__(self):
        self.children = {}    # {'a': TrieNode, 'b': TrieNode, ...}
        self.is_end = False   # 이 노드에서 단어가 끝나는지
```

**세 가지 연산:**

| 연산 | 설명 | 시간 |
|------|------|------|
| insert("apple") | 한 글자씩 따라가며 노드 생성 | O(len) |
| search("apple") | 한 글자씩 따라가며 존재 확인 + is_end | O(len) |
| startsWith("app") | search와 같지만 is_end 안 봄 | O(len) |

---

**왜 쓰냐?**

```
단어 10만 개에서 "app"으로 시작하는 거 찾기:
- 리스트: 10만 개 다 체크 → O(n × len)
- Trie: "a" → "p" → "p" 3번이면 끝 → O(len)
```

**자동완성, 맞춤법 검사, 검색 엔진**이 다 Trie야!
