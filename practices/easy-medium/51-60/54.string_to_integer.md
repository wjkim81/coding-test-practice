**문제: String to Integer (atoi)**

문자열을 정수로 변환하세요. 엣지 케이스가 많아!

```
Input:  "42"         → 42
Input:  "   -42"     → -42
Input:  "4193 word"  → 4193
Input:  ""           → 0
Input:  "+-12"       → 0
Input:  "2147483648" → 2147483647 (INT_MAX 클램핑)
```

규칙:
- 앞 공백 무시
- `+` 또는 `-` 부호 처리
- 숫자 아닌 문자 만나면 중단
- INT 범위 초과시 클램핑 (-2³¹ ~ 2³¹-1)

풀어봐! 🔥
