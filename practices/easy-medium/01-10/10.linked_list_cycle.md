**문제: Linked List Cycle**

단방향 연결 리스트에 **사이클이 있는지** 판별하세요.

```python
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next
```

```
Input:  3 → 2 → 0 → -4 → (back to 2)
Output: True

Input:  1 → 2 → None
Output: False
```
