## Problem 3 — Debug & Fix a Broken Training Loop (Medium-Hard)

**Context:**

A junior engineer wrote the following code to train a small MLP that learns a 2D scalar field (think: a regression model that maps `(x, y)` coordinates to a scalar value like pressure on a 2D plane).

The target function is a simple Gaussian bump:

$$
f(x, y) = \exp\!\left(-\frac{x^2 + y^2}{0.5}\right)
$$

They report that **the loss is not decreasing**, and the predictions look like garbage. They've asked you to look at the code and fix it.

```python
import torch
import torch.nn as nn
import numpy as np

# ---- Data ----
N = 1000
coords = np.random.uniform(-1, 1, size=(N, 2))
values = np.exp(-(coords[:, 0]**2 + coords[:, 1]**2) / 0.5)

X = torch.tensor(coords)
y = torch.tensor(values)

# ---- Model ----
class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 64),
            nn.ReLU(),
            nn.Linear(64, 64),
            nn.ReLU(),
            nn.Linear(64, 1),
        )

    def forward(self, x):
        return self.net(x)

model = MLP()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.MSELoss()

# ---- Training ----
for epoch in range(500):
    pred = model(X)
    loss = loss_fn(pred, y)
    loss.backward()
    optimizer.step()

    if epoch % 50 == 0:
        print(f"Epoch {epoch}: loss = {loss.item():.6f}")
```
