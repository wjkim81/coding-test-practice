## Problem 4 — Multi-class Dice Score from Scratch (Medium)

**Context:**

You're evaluating a semantic segmentation model. Given predicted and ground-truth labels for a batch of 3D volumes (or 2D images — same logic), compute the **Dice score** per class and the **mean Dice** across classes.

The Dice score for a single class $c$ is defined as:

$$
\text{Dice}_c = \frac{2 \cdot |P_c \cap G_c|}{|P_c| + |G_c|}
$$

where $P_c$ is the set of voxels predicted as class $c$, and $G_c$ is the set of voxels labeled as class $c$ in the ground truth.

### Requirements

1. **Vectorized**: no nested Python loops over voxels. A loop over `num_classes` is acceptable.
2. **Handle `ignore_index`**: voxels with this label in `target` are excluded from **both** the intersection and the union counts.
3. **Handle empty classes** (a class with zero voxels in both pred and target): return `NaN` for that class, exclude from mean.
4. **Handle the boundary case** where a class is present in only one of pred/target → standard Dice = 0 for that class (this falls out of the formula naturally).
5. **Shape-agnostic**: should work for any spatial dimensionality (2D images, 3D volumes, even 1D). Don't hardcode shape.

### What I'm looking for

- Correct, vectorized computation
- Careful edge case handling (empty classes, ignore_index)
- Clean, readable code
- Awareness of why each design choice was made

### Why this matters in practice

In medical imaging, **class imbalance is severe** — background dominates, lesion classes can be tiny. Computing Dice carelessly leads to:
- Division by zero when a class is empty
- "Fake good" scores when ignore_index isn't handled (e.g., padding voxels)
- Misleading mean when empty classes are counted as 0 vs NaN
