## Problem 2 — Nearest-Neighbor Field Transfer Between Meshes (Medium)

**Context:**

A common situation in CFD/simulation workflows. You have two meshes:

- **Source mesh**: where a simulation was run. Each vertex has an associated field value (e.g., pressure, velocity magnitude, temperature).
- **Target mesh**: a different mesh (different resolution, different representation, or a standardized mesh for an ML model). You need to "carry over" the source field onto the target.

This also appears constantly in ML pipelines for engineering data — e.g., projecting per-vertex CAD data onto a canonical mesh used as neural network input.

The simplest approach is **nearest-neighbor transfer**: for each target point, find the closest source point and copy its value.

### Requirements

1. **Correctness**: for each target point, find the source point with smallest Euclidean distance and copy its value.
2. **Scale**: N and M can each be up to ~100,000. A naive `(M, N)` distance matrix is risky in memory/time. Think about this.
3. **Scalar/vector field support**: 1D input → 1D output, 2D input → 2D output.
4. **External libraries**: NumPy obviously fine. `scipy` is fair game (you'd use it in real work).
