## Round 6 — Debugging Existing Code / Vectorization

### Problem: Fix and Improve Feature Normalization

A teammate wrote this function to normalize tabular engineering features before training an ML model:

```python
import numpy as np

def normalize_features(X):
    means = X.mean(axis=0)
    stds = X.std(axis=0)

    return (X - means) / stds
```

But there are several issues:

1. `X` may contain `NaN` or `inf`.
2. Some feature columns may have zero standard deviation.
3. `X` may be a Python list, not a NumPy array.
4. If all values in a column are invalid, that column should be left as `NaN`.
5. Invalid entries should remain `NaN` in the output.

Rules:

* Compute mean/std column-wise using only finite values.
* For finite entries:

  * normalize normally if std > 0
  * set to `0.0` if std == 0
* For invalid entries:

  * output should be `NaN`
* If a column has no finite values:

  * output column should be all `NaN`
  * mean/std should be `NaN`
  * valid_count should be `0`
