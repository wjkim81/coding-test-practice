# Round 7 — Lightweight Scientific ML Debugging

A customer reports that your surrogate model sometimes produces unstable predictions.

You are given:

* input features `X`
* model predictions `pred`
* reference simulation values `ref`

Each has shape:

```python
(N,)
```

Some entries may be invalid:

```python
NaN, +inf, -inf
```

You want to identify suspicious samples where the prediction error is unusually high.

---

## Task

Write a function:

```python
def detect_unstable_predictions(X, pred, ref, threshold_std=3.0):
    ...
```

Return:

```python
{
    "unstable_indices": indices_of_unstable_samples,
    "mean_error": mean_abs_error,
    "std_error": std_abs_error,
    "num_unstable": number_of_unstable_samples,
}
```

Rules:

1. Compute absolute error:

```python
abs(pred - ref)
```

2. Only use samples where:

* `X`
* `pred`
* `ref`

are all finite.

3. Define unstable samples as:

```python
abs_error > mean_error + threshold_std * std_error
```

4. Return indices relative to the original arrays.

5. Use NumPy vectorization.

---

## Example

```python
X    = np.array([1,2,3,4,5])
pred = np.array([1,2,3,100,5])
ref  = np.array([1,2,3,4,5])
```

Absolute errors:

```python
[0,0,0,96,0]
```

The sample at index `3` should likely be unstable.
