# Round 3 — NumPy / Simulation Field Preprocessing

## Problem: Normalize Simulation Fields

You are given multiple simulation fields from CFD/FEA-like outputs.

Each simulation field is a 2D NumPy array of shape:

```python
(H, W)
```

Each field represents a scalar physical quantity, for example pressure or velocity magnitude.

You are given:

```python
fields = [field1, field2, field3, ...]
```

Write a function:

```python
def normalize_fields(fields):
    ...
```

that returns:

```python
normalized_fields, stats
```

Where:

```python
normalized_fields
```

is a list of normalized arrays, and:

```python
stats
```

is a dictionary:

```python
{
    "mean": global_mean,
    "std": global_std,
    "count": number_of_valid_values
}
```

Use **global normalization** across all fields:

```python
x_norm = (x - global_mean) / global_std
```

---

## Valid values

Ignore invalid values when computing mean/std:

* `NaN`
* `+inf`
* `-inf`

Invalid values should remain invalid in the output arrays.

---

## Edge cases

Handle:

1. Empty `fields`
2. Fields with different shapes
3. All values invalid
4. `global_std == 0`

---

## Example

```python
import numpy as np

fields = [
    np.array([[1.0, 2.0], [3.0, np.nan]]),
    np.array([[4.0, 5.0], [np.inf, 6.0]])
]
```

Valid values are:

```python
1, 2, 3, 4, 5, 6
```

So:

```python
mean = 3.5
std = np.std([1, 2, 3, 4, 5, 6])
```

Return normalized arrays using those values.

---

## Constraints

You may use NumPy.

Try to avoid unnecessary Python loops over individual elements.

Explain briefly:

1. How you compute stats.
2. How invalid values are handled.
3. What you do when `std == 0`.
4. Complexity.
