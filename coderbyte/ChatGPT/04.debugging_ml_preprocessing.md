## Round 4 — Debugging + ML Preprocessing

### Problem: Clean and Batch Simulation Samples

You are given raw simulation samples. Each sample is a dictionary:

```python
sample = {
    "id": "case_001",
    "features": [1.2, 3.4, 5.6],
    "target": 0.83
}
```

Write a function:

```python
def build_training_batch(samples):
    ...
```

Return:

```python
X, y, valid_ids
```

Where:

```python
X.shape == (N, D)
y.shape == (N,)
valid_ids == list of sample ids
```

Only include samples where:

1. `"features"` exists
2. `"target"` exists
3. all feature values are finite numbers
4. target is finite number
5. all valid samples have the same feature dimension `D`

Use NumPy.

---

### Example

```python
samples = [
    {"id": "case_001", "features": [1.0, 2.0, 3.0], "target": 0.5},
    {"id": "case_002", "features": [2.0, np.nan, 4.0], "target": 0.7},
    {"id": "case_003", "features": [3.0, 4.0, 5.0], "target": 1.1},
]
```

Expected:

```python
X = np.array([
    [1.0, 2.0, 3.0],
    [3.0, 4.0, 5.0],
])

y = np.array([0.5, 1.1])

valid_ids = ["case_001", "case_003"]
```

---

### Edge cases

Handle:

1. Empty samples
2. No valid samples
3. Feature dimension mismatch
4. Missing id
   For missing id, use `None` in `valid_ids`.
