## Round 5 — Geometry + Simulation Error Metric

### Problem: Compare Predicted and Reference Surface Fields

You are given two NumPy arrays:

```python
pred
ref
```

Both represent scalar values sampled on the same 2D surface grid, for example pressure, stress, or velocity magnitude.

Some grid locations are invalid and should be ignored. Invalid values are:

```python
NaN, +inf, -inf
```

Write a function:

```python
def compute_field_error(pred, ref):
    ...
```

Return a dictionary:

```python
{
    "mae": mean_absolute_error,
    "rmse": root_mean_squared_error,
    "max_error": maximum_absolute_error,
    "valid_count": number_of_valid_grid_locations
}
```

Only compare locations where **both** `pred` and `ref` are finite.

---

### Example

```python
pred = np.array([
    [1.0, 2.0, np.nan],
    [4.0, 6.0, 8.0]
])

ref = np.array([
    [1.5, 1.0, 3.0],
    [4.0, np.inf, 10.0]
])
```

Valid comparison locations:

```python
(0,0), (0,1), (1,0), (1,2)
```

Errors:

```python
abs(pred - ref) = [0.5, 1.0, 0.0, 2.0]
```

Expected:

```python
{
    "mae": 0.875,
    "rmse": sqrt((0.25 + 1.0 + 0.0 + 4.0) / 4),
    "max_error": 2.0,
    "valid_count": 4
}
```

### Requirements

1. Use NumPy.
2. Validate that `pred` and `ref` have the same shape.
3. If there are no valid comparison points, raise `ValueError`.
4. Avoid explicit Python loops over grid elements.
5. Briefly explain how this metric would be used in ML model evaluation.
