# Round 2 — Scientific Python / Geometry

### Problem: Point Cloud Bounding Box

You are given a 3D point cloud from a CAD or simulation system.

Each point is represented as:

```python
(x, y, z)
```

Write a function:

```python
def compute_bounding_box(points):
    ...
```

that returns:

```python
{
    "min": (xmin, ymin, zmin),
    "max": (xmax, ymax, zmax),
    "center": (cx, cy, cz),
    "size": (sx, sy, sz),
}
```

Where:

* `min` = minimum coordinate along each axis
* `max` = maximum coordinate along each axis
* `center` = midpoint of bounding box
* `size` = box dimensions

---

### Example

Input:

```python
points = [
    (0, 1, 2),
    (2, 3, 5),
    (-1, 4, 0),
]
```

Expected:

```python
{
    "min": (-1, 1, 0),
    "max": (2, 4, 5),
    "center": (0.5, 2.5, 2.5),
    "size": (3, 3, 5),
}
```

---

## Constraints

1. Do NOT use external geometry libraries.
2. First write a pure Python solution.
3. Then explain how you would optimize it with NumPy for millions of points.
4. Handle edge cases properly.

Take this like a real interview:

* write code
* explain decisions
* mention tradeoffs if relevant.
