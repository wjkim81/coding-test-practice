## Round 1 — Medium Difficulty

### Problem: Simulation Run Aggregator

You are given engineering simulation results from multiple CAD designs.

Each simulation result is represented as a Python dictionary:

```python
runs = [
    {
        "design_id": "wing_001",
        "parameters": {"angle": 5.0, "speed": 30.0},
        "metrics": {"drag": 0.21, "lift": 1.32},
        "status": "ok"
    },
    ...
]
```

Some runs may be invalid:

```python
"status": "failed"
```

or may be missing one or more metrics.

---

### Task

Write a Python function:

```python
def summarize_simulations(runs, target_metric, group_by_param):
    ...
```

that returns a dictionary summarizing valid simulations grouped by one input parameter.

For each value of `group_by_param`, compute:

```python
{
    "count": number of valid runs,
    "mean": mean target metric,
    "min": minimum target metric,
    "max": maximum target metric,
    "best_design_id": design_id with lowest target metric
}
```

Only include runs where:

1. `status == "ok"`
2. `target_metric` exists in `metrics`
3. `group_by_param` exists in `parameters`
4. metric value is numeric

Assume lower `target_metric` is better.

---

### Example

Input:

```python
runs = [
    {
        "design_id": "wing_001",
        "parameters": {"angle": 5.0, "speed": 30.0},
        "metrics": {"drag": 0.21, "lift": 1.32},
        "status": "ok"
    },
    {
        "design_id": "wing_002",
        "parameters": {"angle": 5.0, "speed": 35.0},
        "metrics": {"drag": 0.18, "lift": 1.28},
        "status": "ok"
    },
    {
        "design_id": "wing_003",
        "parameters": {"angle": 10.0, "speed": 30.0},
        "metrics": {"drag": 0.25},
        "status": "failed"
    },
    {
        "design_id": "wing_004",
        "parameters": {"angle": 10.0, "speed": 35.0},
        "metrics": {"drag": 0.22},
        "status": "ok"
    }
]
```

Call:

```python
summarize_simulations(runs, target_metric="drag", group_by_param="angle")
```

Expected output:

```python
{
    5.0: {
        "count": 2,
        "mean": 0.195,
        "min": 0.18,
        "max": 0.21,
        "best_design_id": "wing_002"
    },
    10.0: {
        "count": 1,
        "mean": 0.22,
        "min": 0.22,
        "max": 0.22,
        "best_design_id": "wing_004"
    }
}
```
